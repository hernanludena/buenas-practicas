## Criterio

Este repositorio es un recordatorio técnico, no una decisión automática de implementación. Antes de adoptar una herramienta, validar requisitos, costos, seguridad, soporte vigente y operación. No guardar aquí contraseñas, tokens, datos de tarjetas ni credenciales de cuentas.
